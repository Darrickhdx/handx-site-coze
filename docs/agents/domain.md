# Domain docs

本项目采用单一领域上下文。

## 修改前应阅读

- 根目录 `CONTEXT.md`：项目统一领域词汇。
- `docs/adr/`：与本次改造区域相关的重要架构决策。

如果文件尚不存在，正常继续，不要为了填充目录而创建空文件。
`domain-modeling` 会在第一个领域术语真正确定时创建 `CONTEXT.md`，
并只在决策难以逆转、缺少背景会令人意外、且确实存在权衡时创建 ADR。

## 使用规则

- 规格、任务、测试名称和代码接口应采用 `CONTEXT.md` 中的规范术语。
- `CONTEXT.md` 只保存领域词汇及其关系，不保存实现细节或任务计划。
- 如果新方案与既有 ADR 冲突，必须明确指出并重新讨论，不能静默覆盖。
